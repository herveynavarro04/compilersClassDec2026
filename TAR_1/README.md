# Assignment #1: Basic Data Structures

## Objective

Develop and/or document an appropriate implementation of the following classes:

- **STACK** (LIFO)
- **QUEUE** (FIFO)
- **TABLE / HASH / DICTIONARY** (ordered)

> You may implement them from scratch or use a public library.

Each class must include methods supporting the main classic access and manipulation operations. They don't need to be classes if the development language doesn't support them.

**Suggestion:** Complete this assignment in the language you plan to use for the course mini-project.

## Deliverables

1. **Source code files** (plain text)
2. **A small demo program** that manipulates these structures to show they work
3. **A description of the test cases** used to validate the structures

This assignment must also be committed to your Git repository, since it will become part of your project.

## Use of AI

AI tools are allowed, as long as you state exactly:

- Which tools you used
- What queries (prompts) you made
